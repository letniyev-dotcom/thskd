# Общение: экран списка чатов

Только release, подпись релизным ключом app/release.jks (alias chats).
1. Распакуй архив и залей все файлы в репозиторий GitHub (вместе с папкой .github).
2. Вкладка Actions > Release APK > внизу в Artifacts скачай chats-release-apk.
Репозиторий лучше держать приватным: в нём лежит ключ подписи.
