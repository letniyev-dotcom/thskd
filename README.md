# Общение: экран списка чатов

Только release, подпись релизным ключом app/release.jks (alias chats).
1. Распакуй архив и залей все файлы в репозиторий GitHub (вместе с папкой .github).
2. Вкладка Actions > Release APK > внизу в Artifacts скачай chats-release-apk.
Репозиторий лучше держать приватным: в нём лежит ключ подписи.

Очередь «можно взять» теперь не вкладка, а «сторис» в шапке: ряд аватарок с именем и временем ожидания.
Время ожидания — под именем, 12sp medium.
Очередь сворачивается вслед за прокруткой списка (1:1 с пальцем), отпустил на полпути — доезжает пружиной до ближайшего положения.
Вместо андроидовского оверскролла своя тугая резинка: и у списка, и у ряда очереди по горизонтали.
Тёмная тема: удержание на пустом месте или тап по кнопке архива (слева в шапке). Слева в шапке архив, справа поиск. Папки: выбранная в пилюле.
