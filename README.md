# Общение: экран списка чатов

Только release, подпись релизным ключом app/release.jks (alias chats).
1. Распакуй архив и залей все файлы в репозиторий GitHub (вместе с папкой .github).
2. Вкладка Actions > Release APK > внизу в Artifacts скачай chats-release-apk.
Репозиторий лучше держать приватным: в нём лежит ключ подписи.

Очередь «можно взять» — «сторис» в шапке без контейнера: крупные кружки (56dp) с шагом 76dp, имя и время ожидания под ними.
Сворачивание как у Telegram: кружки волной стягиваются в стопку из трёх рядом с заголовком, остальные растворяются, подписи гаснут. Сворачивается вслед за пальцем 1:1.
Раскрытие тянется с сопротивлением (вполовину), а когда отпустил, блок сам плавно доезжает (хватит пятой части пути или броска вниз). У верха кружки слегка растягиваются.
Папки (все / непрочитанные / общие) без плашки под выбранной: выбранная выделена цветом.
Вместо андроидовского оверскролла своя тугая резинка у списка.
Тёмная тема: удержание на пустом месте или тап по кнопке архива (слева в шапке). Слева в шапке архив, справа поиск. Папки: выбранная в пилюле.
